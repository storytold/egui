# Test fonts

`SpaceGrotesk-Digits.ttf` is a subset of [Space Grotesk](https://github.com/floriankarsten/space-grotesk) v2.000 (SIL Open Font License 1.1, see `OFL.txt`):
the variable font instanced at `wght=400` and cut down to the digits `0`–`9` and the `tnum` feature with fontTools.
Its default digits are proportional, so tests can check that `tnum` makes them tabular.
